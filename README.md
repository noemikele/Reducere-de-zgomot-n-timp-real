# Reducere-de-zgomot-n-timp-real
Aplicație Python pentru reducerea zgomotului de fundal în timp real prin filtru digital trece-bandă Butterworth (150–3500 Hz) cu SciPy și sounddevice. Captează fluxul audio, îl curăță live, salvează rezultatele WAV și generează grafice comparative timp/frecvență (FFT).
